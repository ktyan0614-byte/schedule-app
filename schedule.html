尚未設定同步
① 設定 Firebase 資料庫 URL
  1. 前往 console.firebase.google.com
  2. 建立新專案（免費）
  3. 左側選 Build → Realtime Database
  4. 點「建立資料庫」，地區選亞洲
  5. 前往「規則」標籤，將內容改為：
    {"rules":{".read":true,".write":true}}
    然後發布
  6. 回到「資料」標籤，複製最上方的 https://xxx.firebasedatabase.app 網址
  7. 貼到上方輸入框，點儲存

⚠️ 此 App 需部署到 HTTPS 網址才能完整使用 PWA 功能（建議用 Vercel / Netlify / GitHub Pages 免費部署）
